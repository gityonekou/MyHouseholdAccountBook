# MyHouseholdAccountBook
マイ家計簿のWebアプリケーションです。<br>
SpringBootを使って作成しています。<br>
バージョン1.0.0以降、生成AI(Claude Code)を使っています。<br>
<br>
<br>
「develop-1.03」ブランチは、以下機能追加用のブランチです。<br>
【追加機能一覧】<br>
・銀行口座登録管理、支払方法登録管理の追加と金額入力系の画面に支払方法の登録を追加・参照画面に支払方法項目の表示を追加：feature-1.03-dev1<br>
・クレジットカードポイント減算(翌月引落のクレジットカード利用代金のうち、指定店舗の利用代金からポイント利用分を減算できるようにする)：feature-1.03-dev2<br>
・積立金残高管理機能の追加：feature-1.03-dev3<br>
・店舗・支払方法別買い物照会 | 指定した店舗・支払方法・集計期間で買い物明細を絞り込み、利用代金合計を照会できるようにする。：feature-1.03-dev4<br>
<br>
